# Retrieval benchmark v1 — scaffolding, not measured

The ten EXAMPLE prompts were authored to demonstrate question structure. They were not sampled from the paper corpus, not reviewed by astronomers, and contain no gold answers or relevance labels. No retrieval-quality numbers may be reported from them. The blank authoring template intentionally contains no documents or questions.

Astronomers should add document IDs/text with source URLs, provenance, access dates and redistribution permission; add independently authored queries with IDs and `review_status: unreviewed`. Record reviewer identity and relevance rationale before setting `review_status: reviewed` and `gold_document_ids`. Null gold means unknown, not a negative label. Title-derived examples must retain `title_derived: true` and `unreviewed`; build independently reviewed research items separately. License and corpus redistribution rights remain OPEN QUESTIONS.

Run `node benchmarks/retrieval/run.mjs benchmarks/retrieval/examples.json`. The loader enforces v1 envelope, duplicate IDs, document references and review gates in addition to the published JSON schema. Missing embeddings skip dense and both hybrid arms. Supply compatible, actually computed document/query vectors; their model/version and provenance must be recorded in the dataset. No embedding API is called. Supply a reranker via the `run` interface for hybrid+rerank; none is enabled by default. Alternative retrievers return arrays of unique document IDs.

BM25 uses k1=1.2, b=0.75; RRF uses 60. Recall@k uses all labelled relevant documents as denominator. MRR uses the first relevant result in the complete returned ranking. Only reviewed, gold-labelled research items receive metrics. Reports include per-arm executed and skipped items/reasons and labelled subset size. CIs are question-level percentile bootstrap (2,000 draws, fixed seed 1729), not evidence of generalization. Small samples, incomplete labels, corpus selection, embedding provenance and reranker bias limit interpretation. A single labelled question gives a degenerate interval. No performance claim is established by algorithm unit tests.
