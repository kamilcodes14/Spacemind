# Numeric catalogue checks v1 — implemented, not measured

Only NASA Exoplanet Archive TAP is used: `https://exoplanetarchive.ipac.caltech.edu/TAP/sync`. Official references: [TAP](https://exoplanetarchive.ipac.caltech.edu/docs/TAP/usingTAP.html), [columns](https://exoplanetarchive.ipac.caltech.edu/docs/API_PS_columns.html). The default `ps` solution is selected, not a claim that it is the only scientific solution. True mass columns are used, never silently substituted with mass*sin(i).

The deliberately narrow grammar accepts one explicit Kepler-, K2-, TOI-, WASP-, HAT-P-, HD, GJ or TRAPPIST-1 planet name and one period/radius/mass statement per cited claim. Example grammar: `Kepler-22 b has a period of VALUE ± ERROR days [1].` This is grammar documentation, not a catalogue measurement. It supports signed decimals, e notation, ×10^exponent, symmetric and +upper -lower errors. Negated, qualified, multiple-name and unparsed claims receive no label. No aliases, pronouns or general natural-language inference are attempted. Other naming families and SIMBAD are future work.

Periods support days/hours/seconds. Radius/mass support explicit Earth/Jupiter units, selecting matching native columns rather than guessing physical-unit conventions. Unrecognized units, missing uncertainties, non-measurement limit flags and zero combined error yield `not comparable`. Missing/duplicate exact-name rows and provider failure yield no label or user-visible error. Existing excerpt support/confidence checks are retained independently.

The descriptive convention is `tension` above 3 sigma, `agrees` otherwise. Sigma uses the claim and catalogue directional uncertainties toward each other, combined in quadrature. This assumes independent errors with comparable uncertainty conventions; shared observations, systematic errors, non-Gaussian errors and reference differences can invalidate that interpretation. Neither label proves scientific correctness. Review original references. Accuracy gain: not measured.

At most 20 claims/names and one cached batch per answer; 3-second budget includes cache and body reading; response cap 64 KB and 20 rows. Redirects are rejected. The existing provider cache retains the actual retrieval timestamp for one hour. Names alone are sent in the query, not full claims or conversations. Cancellation cannot forcibly stop an already-started cache database operation, but the answer returns at the deadline and timed-out lookup results are not labelled.

Tests use explicitly synthetic mock responses, not recorded NASA observations. Local tests cover parsing/conversion, asymmetric errors, ambiguity, failure/size/deadline, cache provenance, research citation persistence and DOM-free UI metadata. Browser rendering and live provider acceptance have not been verified. No migration or new secret is required. Deploy the research Edge Function and rebuild/release the frontend when authorized; no deployment was performed here.
